CHAPTER 01 / SCALE

世界とつながる、その規模。

ひとつのコミットから、世界の開発へ。

FACT 012022年調査

プロ回答者の約97%が、Gitを使う。

2022年のStack Overflow調査では、プロの開発者として回答した人の96.65%がGitを利用していました。チーム開発を学ぶ最初の一歩が、世界の開発現場につながっています。

数字・表現の読み方

世界の全開発者を数えた割合ではなく、調査のプロ回答者の割合です。

FACT 022026.10.27確認

コードの置き場所は、8億以上。

GitHubには8億以上のリポジトリがあります。リポジトリはコードだけでなく、その変更の記録も保管する場所。小さな練習から大きな開発まで、同じ仕組みが使われています。

数字・表現の読み方

公開リポジトリだけの数ではありません。リポジトリ数と、独立した製品の数は異なります。

FACT 032026.10.27確認

世界中の開発者が、同じ場所に集まる。

GitHubは公式に「225M+ Developers」と紹介しています。個人の学習、オープンソースへの参加、企業の開発。さまざまな人がこのコミュニティに関わっています。

数字・表現の読み方

公式のDevelopers表記に基づきます。全員が職業プログラマーという意味ではありません。

FACT 042025年版

平均すると、毎秒ひとり以上。

2025年版Octoverseは、過去1年間にGitHubへ新たに参加した開発者を、平均して毎秒1人以上と表現しています。いま学び始める人も、大きな流れの一員です。

数字・表現の読み方

過去1年間の平均を表す数字です。現在の登録をリアルタイム表示しているわけではありません。

FACT 052025年版

日本のコミュニティも、世界トップクラス。

2025年版の発表では、日本のGitHub開発者コミュニティは450万人を超え、国・地域別で世界6位。世界の開発は、遠い国だけの話ではありません。

数字・表現の読み方

2025年版の集計です。世界の全プログラマー人口の順位ではありません。

FACT 062025年8月

TypeScriptが、首位になった年。

2025年8月、GitHub上のコントリビューター数に基づく言語ランキングで、TypeScriptが首位になりました。JavaScriptの学びは、その先の技術にもつながっています。

数字・表現の読み方

GitHubのコントリビューター数ベース。コード行数や世界全体の人気順位ではありません。

CHAPTER 02 / EVERYDAY

いつもの製品、その裏側。

遠い世界の技術じゃない。すぐそばにある。

FACT 072026.10.27確認

大企業も、同じプラットフォームを使う。

Fortune 100に入る企業の90%がGitHubを利用しています。今日触れるツールは、学生の練習用に限らず、企業の開発にも使われるものです。

数字・表現の読み方

Fortune 100という特定の企業群の割合です。世界中の企業の90%ではありません。

FACT 08公式ドキュメント

スマートフォンの、その中にもGit。

Androidのオープンソース開発ではGitとRepoが使われています。Repoは複数のGitリポジトリをまとめて扱うための道具。大きな製品では、複数のリポジトリが協力して動きます。

数字・表現の読み方

Android Open Source Projectのソース管理の話です。

FACT 09公式ドキュメント

ブラウザーをつくる現場でも。

Chromeなどの基盤となるオープンソースプロジェクトChromiumでも、ソースコードの取得や開発にGitが使われます。いつも使うブラウザーの裏側にも、変更履歴の積み重ねがあります。

数字・表現の読み方

Gitを使うことと、GitHub上で開発することは別です。

FACT 10公式リポジトリ

コードを書く道具も、コードを公開している。

VS Codeの基盤となるCode - OSSは、MicrosoftのGitHubリポジトリでコミュニティと公開開発されています。ソースやIssueをのぞくと、普段のエディターをつくる過程に触れられます。

数字・表現の読み方

配布版VS Codeやすべての拡張機能まで同じライセンスという意味ではありません。

FACT 11公開事例

日本の企業にも、活用の広がり。

ソニーのオープンソース公開、NTTドコモのGitHub Enterprise利用、ZOZOの導入事例。異なる使い方を通じて、日本の企業でもGitHubが活用されています。

数字・表現の読み方

各社の公開事例です。各社すべての開発基盤が統一されているとは限りません。

CHAPTER 03 / HISTORY

小さな始まり、大きな歴史。

生まれた理由を知ると、道具の見え方が変わる。

FACT 122005年の初期コア

Gitの原型は、約10日で生まれた。

2005年、Linuxの開発を支えるため、Linus TorvaldsがGitの初期コアを制作しました。本人の振り返りによると、その原型にかけた時間は約10日でした。

数字・表現の読み方

現在のGitの全機能が10日で完成した、という意味ではありません。

FACT 132025年の例

140万回の変更を、ひとつの歴史に。

Git公式サイトの2025年の例では、Linuxの約140万コミットを含む履歴が約5.5GB。ソース本体は約1.7GBです。変更を記録する仕組みが、巨大な開発の積み重ねを扱っています。

数字・表現の読み方

2025年の公式例であり、現在のリポジトリを測った値ではありません。

FACT 142018年

GitHubが、Microsoftの一員に。

2018年、Microsoftは75億ドル規模の株式対価でGitHubを買収すると発表。同年10月26日に買収が完了しました。開発者の協働の場が、大きな注目を集めた出来事です。

数字・表現の読み方

Gitという技術自体をMicrosoftが買収した、という意味ではありません。

CHAPTER 04 / BEYOND

コードは、地球を越えて。

北極へ、月へ、火星へ。貢献の行き先は無限大。

FACT 152020年のスナップショット

コードを、北極圏に残す。

GitHub Archive Programは、2020年2月2日時点のアクティブな公開リポジトリのスナップショットを北極圏で保存。1,000年の耐久性を想定したフィルムに、ソフトウェアの歴史を託しました。

数字・表現の読み方

1,000年間の保存保証や、現在の全リポジトリの常時バックアップではありません。

FACT 16NASA公式組織

宇宙開発のコードも、のぞける。

NASAは公式GitHub組織でソフトウェアを公開しています。宇宙や科学を支える技術の一部も、私たちがソースコードを読める場所にあります。

数字・表現の読み方

NASAの全システムがGitHub上で動く、という意味ではありません。

FACT 172021年の紹介

知らないうちに、火星を飛ばしていた。

火星ヘリコプターIngenuityが利用したオープンソースソフトウェアには、約1万2,000人の開発者が貢献していました。ひとつの貢献が、思いがけない場所で役立つことがあります。

数字・表現の読み方

利用されたOSSへの貢献者です。NASAが直接雇用した開発者数ではありません。

FACT 18アポロ11号の保存資料

月へ行ったコードを、いま読む。

アポロ11号の誘導コンピューターのソースコードをGitHubで閲覧できます。紙資料をもとにデジタル化された歴史的なコードを、現代のツールで読めるのです。

数字・表現の読み方

Virtual AGC・MIT Museum経由の資料を使ったコミュニティ保存版。NASAの公式投稿でも、当時Gitを使っていたという話でもありません。
